# Dataset Information

## Source
CMS Medicaid State Drug Utilization Data

## Coverage
2016–2025

## Description
The dataset contains Medicaid drug utilization and reimbursement information across U.S. states, including:
- utilization type
- prescription counts
- units reimbursed
- total reimbursement amounts
- Medicaid and non-Medicaid reimbursement values

## Note
Raw CSV files are not included in this repository due to dataset size considerations and because the source data is publicly available through CMS/Medicaid.gov.

## Access
https://www.medicaid.gov/medicaid/prescription-drugs/state-drug-utilization-data/index.html
